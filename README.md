# Angular Momentum Lab

Interactive undergraduate Engineering Dynamics demonstrations, designed for students to adjust physical parameters and observe how angular-momentum vectors and components change.

## Simulations

- Flywheel — fixed-axis rotation
- Rolling disk — angular momentum about different reference points
- Slider–crank mechanism — orbital and spin contributions
- Gyroscope — angular momentum components in 3D
- Rotating platform — conservation of angular momentum

Each simulation includes controls, motion visualization, angular-momentum components, equations, time history, and a conceptual question. Quantities use SI units. Models are idealized for teaching.

## Run locally

Open `index.html` in a modern browser. All code is plain HTML, CSS, and JavaScript with no build step or dependencies.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, and click **Save**.
4. Wait for GitHub Pages to publish the website.
